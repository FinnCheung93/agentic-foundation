## Core Routing

| Information | Home |
|---|---|
| 工作入口与共同底线 | `AGENTS.md` |
| 项目简述、活跃资料、已启用模块 | 根 `README.md` |
| 当前推进、阻塞、下一步、共同注意 | `STATE.md` |
| 当前有效的长期约束、禁区、稳定偏好 | `PRINCIPLES.md` |
| 发生过的工作、判断、验证、返工和材料引用 | `LOG.md` |
| 未来需要解释“为何不是另一种做法”的已确认取舍 | 已启用的 Decision Records |
| 不再活跃但仍需保留的资料 | 已启用的 Archive 索引 |

先判断信息性质和已有 artifact。已有材料足以承载细节时，治理文件只保留必要摘要或入口。用户已明确且具有长期意义的规则可以进入正式文件；未授权的新结构、迁移或模块先说明候选与影响，等待确认。

## Evolve Deliberately

纠偏、漂移、重复问题或关键阶段收尾，可能暴露长期协作需要调整。agent 可以主动判断并提出建议；不为完整性制造文档，也不把一次性经验升级成长期规则。

扩展能力只在真实需要并获确认后创建。启用后在根 `README.md` 登记入口；其详细规则由模块自身承载。
