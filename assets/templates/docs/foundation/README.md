## Core Routing

| Information | Home |
|---|---|
| 工作入口与共同底线 | `AGENTS.md` |
| 项目简述、活跃资料、已启用模块 | 根 `README.md` |
| 当前推进、阻塞、下一步、共同注意 | `STATE.md` |
| 当前有效的长期约束、禁区、稳定偏好 | `PRINCIPLES.md` |
| 发生过的工作、判断、验证、返工和材料引用 | `LOG.md` |
| 未来需要解释“为何不是另一种做法”的已确认取舍 | 已启用的 Decision Records |
| 不再活跃但仍需保留的资料 | 已启用的 Archive 索引 |

先判断信息性质和已有 artifact。细节在合适的来源保存，其余位置只更新用途所需且确有变化的摘要或引用。记录可以长期积累，默认读取的信息应随当前工作需要调整。

用户已明确且具有长期意义的规则可以进入正式文件；新模块和超出已授权范围的结构变更先说明影响并确认。

## File Maintenance

创建、修改材料或阶段收尾时，按实际需要整理涉及的文件，沿用项目的组织习惯。拆分、合并或归档后更新受影响的活跃入口与引用，并确认内容仍可找到；历史内容保留，通过索引说明去向。

范围内可恢复的日常整理直接处理；覆盖、不可恢复删除、高风险迁移或扩大范围，先说明影响和回退方式并确认。以便于查找和维护为准，保留合理结构。

## Evolve Deliberately

纠偏、漂移、重复问题或关键阶段收尾，可能暴露长期协作需要调整。agent 可以主动判断并提出建议；不为完整性制造文档，也不把一次性经验升级成长期规则。

扩展能力只在真实需要并获确认后创建。启用后在根 `README.md` 登记入口；其详细规则由模块自身承载。
