# Record Routing

Choose the smallest existing artifact that preserves what future work actually needs.

| Need | Preferred home |
|---|---|
| Current progress, next move, active blocker, shared attention | `STATE.md` |
| Current long-lived rule, stable preference, boundary | `PRINCIPLES.md` |
| Detailed timeline, work performed, verdict, evidence or artifact link | `LOG.md` |
| Confirmed important tradeoff whose rationale will matter later | Decision Record, if enabled |
| Historical material that should leave the active map | Archive index, if enabled |
| Project overview or active entry point | Root `README.md` |

Use references rather than duplication. `STATE.md` is revised instead of appended. `LOG.md`
can retain detailed chronology. A conclusion that currently guides work should identify enough
evidence and scope to be rechecked when the relevant object, boundary, or acceptance condition
changes.

When a meaningful failure has escaped an existing defense, retain the smallest useful chain:
what failed, the cause or current hypothesis, the repair, the proportionate prevention or
recheck, and where the evidence lives. Do not turn ordinary friction into a permanent process.
