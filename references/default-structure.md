# Default Structure

New projects receive only the following living core:

```text
AGENTS.md
README.md
docs/
  foundation/
    README.md
    PRINCIPLES.md
    STATE.md
    LOG.md
```

`AGENTS.md` gives a compact entrance and shared work baseline. The root `README.md` is the
project's map of active materials. `docs/foundation/README.md` routes governance information;
it is not a second project map. `STATE.md` is revised as a current handoff snapshot.
`LOG.md` may be detailed and grow over time, because it is not the default reading path.
`PRINCIPLES.md` contains only current long-lived constraints.

Do not create `docs/README.md`, decision records, archive, review, hook, context, QA, TDD,
suggestion, or check documents merely for completeness. A project may later add them when a
real need and confirmation exist.
