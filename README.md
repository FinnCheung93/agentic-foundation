## Agentic Foundation

为长期人机协作建立轻量项目地基。
默认生成根 `AGENTS.md`、根 `README.md` 和 `docs/foundation/`。

```text
Agentic Foundation 用于初始化、检查、增量同步或扩展项目地基。
它不写 PRD、Specs、计划或架构；它负责入口、地图、路由、当前接手快照和详细历史时间线。
```

## 它能帮你做什么

- 建立 agent 开工入口和项目资料地图
- 记录长期原则、当前状态和详细历史
- 保护测试、检查、评审和验收标准不被实现反向驯服
- 将 Decision Records、archive、hooks、subagent workflow 等作为按需追加能力
- 检查已有 `.foundation/`、`docs/foundation/` 或遗留治理文件，在授权范围内增量同步
- 保留用户内容、项目特有规则和历史记录，不整文件覆盖

## 默认结构

```text
AGENTS.md
README.md
docs/
  foundation/
    README.md
    PRINCIPLES.md
    STATE.md
    LOG.md
```

不默认创建 `docs/README.md`、`SUGGESTIONS.md`、`CHECKS.md`、Decision Records、归档、review、hooks、QA 或 TDD 目录。

## 使用方式

将本目录作为 Codex skill 安装或放入你的 skills 目录中，由 Codex 在项目初始化、同步或追加地基模块时触发。
